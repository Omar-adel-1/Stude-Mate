# StudyMate — Learning Companion UI

StudyMate is a modern educational mobile app UI concept designed to help learners discover courses, keep track of their learning progress, and manage their learning profile in one place.

> **Project scope:** UI design / interface concept. This repository contains a Flutter project, but this README describes the StudyMate screens and design shown in the project visuals; it does not claim that every screen or learning feature is fully implemented.

## ✨ UI Highlights

- **Splash screen** with StudyMate branding
- **Onboarding screens** introducing self-paced learning and progress tracking
- **Authentication UI** for login and account registration
- **Home dashboard** with featured courses and learning progress
- **Course catalog** with course categories and progress indicators
- **My Courses screen** for viewing enrolled courses
- **Course details screen** with course information and a learning call to action
- **Navigation drawer** for switching between app sections
- **Profile screen** with learning statistics and account options
- **Settings screen** for preferences and account management

## 🎨 Design Goals

- Clean, modern educational experience
- Consistent purple visual identity
- Clear information hierarchy and readable course cards
- Simple navigation across the main learning flows
- A focused layout for course discovery and progress tracking

## 🚀 Getting Started

### Prerequisites

- Flutter SDK installed
- Dart SDK (included with Flutter)
- Android Studio or VS Code with Flutter and Dart extensions
- An emulator or a physical device

### Run the Flutter project

1. Clone the repository:

   ```bash
   git clone https://github.com/Omar-adel-1/Stude-Mate.git
   ```

2. Open the project folder:

   ```bash
   cd Stude-Mate
   ```

3. Install dependencies:

   ```bash
   flutter pub get
   ```

4. Run the app:

   ```bash
   flutter run
   ```
